Welcome to my new blog. This is the first post, written in **Markdown** and rendered at build time.

## Why Markdown?

I wanted a place to write short notes and posts without touching JSON files or JSX for every entry. Markdown gives me:

- Familiar syntax I already use every day
- Easy versioning in Git — each post is just a file
- No CMS or database to maintain
