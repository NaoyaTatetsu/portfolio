This site's blog is powered by plain Markdown files instead of a database or headless CMS.

### The pipeline

1. Posts live under `content/blog/<locale>/<year>/<yyyymmdd>.md`, one file per post.
2. Each file starts with frontmatter (`title`, `date`, `excerpt`).
3. At request time, [`gray-matter`](https://github.com/jonschlinkert/gray-matter) parses the frontmatter and [`remark`](https://github.com/remarkjs/remark) converts the body to HTML.
4. The list page reads only the frontmatter for speed; the detail page renders the full HTML.

### Adding a new post

Just drop a new `.md` file into the right locale and year folder — no code changes required.
