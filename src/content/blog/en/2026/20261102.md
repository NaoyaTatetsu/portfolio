## Introduction

I sent two PRs to [Orca](https://orca.dev), the ADE I use every day, and both got merged!</br>
This was my first open source contribution, so I want to write down what I built and how it went.

## Background

As I mentioned in [My 2026 Development Environment](/en/blog/20261004/), I use Orca to manage my AI agent sessions, and I keep all my tasks in GitHub Projects.</br>
Orca can show GitHub Projects inside the app, but it could **only show Table views**. GitHub Projects has three view types: Table, Board, and Roadmap. The Roadmap and Board tabs were disabled as "unsupported."

Looking at the issues, Board support had a `help wanted` label, and so many people had asked for it that several duplicate requests had been closed. There was an issue asking for Roadmap support too.</br>
I use this feature every day, so I decided to build it myself!

## PR 1: Showing Roadmap views as a timeline

https://github.com/stablyai/orca/pull/17795

This PR shows Roadmap views as a timeline, much like on github.com.

- Each issue or PR becomes a horizontal bar, placed by its start and target dates on a month, quarter, or year grid
- A line marks today
- Bars are colored by a single-select field such as Status, and clicking one opens the existing item dialog
- Items without dates stay visible, tagged "No dates"

![Roadmap view (month zoom)](https://raw.githubusercontent.com/NaoyaTatetsu/playground/main/screenshots/after-month.png)

The hardest part was deciding **which date fields to place the bars by**. GitHub's GraphQL API doesn't tell you which fields a Roadmap view uses for its start and target dates.</br>
So Orca now guesses in this order: date fields named Start / Target, then the view's first two date fields, then an iteration field, then a single date field (shown as a point). Roadmap views often hide their date fields from the column list, so as a last resort it looks at the dates each item actually has.

The change was about 1,700 lines, with around 30 new tests.</br>
It was merged just five days after I opened it! A maintainer merged in main, added some display fixes and tests, and then merged it.

## PR 2: Showing Board views as a kanban

https://github.com/stablyai/orca/pull/19074

Next, I made Board views show up as a kanban. Dragging a card to another column also changes its status!

- Columns come from the view's own grouping field (falling back to Status)
- Empty columns, and columns for items pointing at a deleted option, show up just like on github.com
- Dragging uses the same update path as changing a status in the Table view (the screen updates first and rolls back on failure)

![Board view](https://raw.githubusercontent.com/NaoyaTatetsu/playground/main/screenshots/board-after.png)

Drag and drop is where I got stuck. React's `onDrop` handlers never fired at all!</br>
It turned out that Orca stops native drop events before they reach React, so it can handle file drops. I followed the same approach as another kanban in the app and caught the drop with a capture listener on the document.

This one took about a month from opening to merge. Along the way I got a review from another contributor too, and in the end a maintainer added some fixes and merged it.</br>
When it was merged, they wrote "Thanks for always making cool PRs," which made me really happy!

## What I Learned

- **Write a thorough PR description**</br>
Orca's PR template has sections for an ELI5 (explain it like I'm five), before/after screenshots, testing, and whether AI was used. Just filling in the template covered pretty much everything a reviewer would want to know.
- **AI reviews are fast**</br>
As soon as I opened a PR, AI reviewers like CodeRabbit left comments. Being able to fix the small stuff before a human looked at it was a big help!
- **Building with Claude Code**</br>
I built both PRs with Claude Code, and handled the design decisions, review, and testing on the real app myself. I said so in the PRs too. Even for fairly large features, I could contribute the same way I work every day.

## Wrapping Up

It feels great to add a feature I wanted to a tool I use every day! I now run my tasks while looking at Roadmap and Board views right inside Orca.</br>
Next time I want something, I'll try sending another PR!
