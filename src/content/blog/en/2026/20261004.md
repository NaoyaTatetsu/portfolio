At work, I build products powered by generative AI, and I also touch the backend and infrastructure.</br>
In a word, this was **the year I handed my terminal over to AI agents**.

## ADE

### Orca

I use it to run AI agent sessions side by side, one per task. When I start a task, it automatically creates a `git worktree` and runs the agent inside it, which is really handy. I'm actually writing this post inside the `feat/20261004-blog` worktree.</br>
No matter how many tasks I have going, their working directories never get mixed up, and it picks up hooks to notify me when an agent starts or finishes.

## Shell

### zsh + Starship

I just use zsh, which ships with macOS. My prompt is Starship, with a minimal setup that only shows the directory and git status.</br>
I like that it's easy to manage everything in `starship.toml`, like this:

```toml title="starship.toml"
format = """\
$directory\
$git_branch\
$git_status\
$fill\
\n$character\
"""

[git_status]
ahead = '⇡${count}'
behind = '⇣${count}'
modified = '!${count}'
```

I have Cursor installed, but I barely use it. I only open it to look at diffs or search, mostly out of habit.

## AI Tools

### Claude Code

Almost all of my development, document writing, and task management goes through Claude Code. I manage its version with mise.</br>
I occasionally use other AI tools too, but I've gotten used to Claude Code and it's capable enough, so it's my main one.

### Obsidian

This was the biggest win of the year. It's not an AI tool, but I use it as a "second brain" and have Claude Code write the notes.</br>
My daily records are all written by Claude Code.

- **Automated work logs**</br>
Claude Code pulls just the facts out of each session's record, summarizes them with `claude -p`, and saves them as notes in the vault. Being able to search later for "why did I do it that way again?" is a lifesaver.
- **Morning and evening commands**</br>
`/morning` pulls my calendar and tasks into that day's daily note, and `/evening` summarizes what happened on GitHub and in Claude Code.
- **GitHub Projects as the single place for tasks**</br>
I don't keep a task list in the vault. Instead, `/task` opens an issue and adds it to a Project.
- **Run anything that doesn't need AI every morning with launchd**</br>
Routine jobs like rebuilding the index or checking the vault run cron-style, without involving AI at all.
- **Other**</br>
It also pulls in information from Slack conversations and meeting notes on Google Drive and organizes it. It can create tasks and notes from that information too.

The rules live in a `CLAUDE.md` at the root of the vault. They're things like "don't copy external data into the vault (keep only links and summaries)" and "never create a note without frontmatter." Claude Code reads these and writes notes that follow them.

## Runtimes / Package Management

- **Homebrew**</br>
For GUI apps and any command-line tools I don't install with mise.
- **mise**</br>
For language runtimes and CLI tools in general. I switched over from asdf last year.

## Git / GitHub

- **gh CLI**</br>
I use it for working with PRs and issues, and for adding tasks to GitHub Projects.
- **lazygit**</br>
I launch it with an `lg` alias. It's great when I want to stage changes while looking at the diff.
- **Renovate**</br>
I dropped Dependabot for Renovate on this site. Renovate merges patch and minor updates on its own once CI passes, and I only review majors myself.

## Other

### For development

- **OrbStack**</br>
A replacement for Docker Desktop. It's fast.
- **aws-cli**</br>
I often let AI use it for debugging.

### Everything else

- **Remotion**</br>
Sometimes I need a video after building a prototype, so I use Remotion when I want AI to whip one up quickly.
- **Raycast**</br>
Launcher and window resizing.
- **Hammerspoon**</br>
I've mapped `ctrl+A` to toggle Chrome's vertical tabs (the sidebar). It's only active while I'm using Chrome, so `ctrl+A` works normally in other apps. Here's the code:

https://github.com/NaoyaTatetsu/dotfiles/blob/main/.hammerspoon/init.lua

- **Karabiner-Elements**</br>
Since I use a US keyboard, pressing the left or right ⌘ on its own switches between alphanumeric and kana input.
- **Clipy**</br>
Clipboard history.
- **MeetingBar**</br>
Shows my calendar events through the next day in the menu bar.
- **Google Japanese Input**</br>
The built-in Mac Japanese input just doesn't cut it for me, so I use this instead.

## What Changed Since Last Year

| Before | After | Why |
| --- | --- | --- |
| WezTerm + tmux | Orca | I wanted an easier way to manage agent sessions |
| Dependabot | Renovate | I wanted fine-grained control over when to auto-merge (once all CI checks pass) |
| Throwaway notes | Obsidian + Claude Code | I wanted work logs and the reasoning behind decisions saved in a searchable form |

## Wrapping Up

Looking back, my terminal has become a home for agents, and notes have become something agents write for me.</br>
So many new tools came out this year that I tried pretty much everything I could, and this is where I landed.
I want to keep things as simple as I can going forward.
