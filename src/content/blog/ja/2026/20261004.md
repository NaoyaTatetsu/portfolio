## はじめに

仕事では生成 AI を使ったプロダクトを作っていて、バックエンドやインフラも触ります。</br>
一言でいうと、今年は **ターミナルを AI エージェントに明け渡した年** でした。

## ADE

### Orca

AI エージェントのセッションを、タスクごとに並べて管理するのに使っています。タスクを始めると勝手に `git worktree` を切って、その中でエージェントを動かしてくれるのが便利です。この記事も `feat/20261004-blog` の worktree の中で書いています。</br>
タスクをいくつ並べても作業ディレクトリが混ざらないし、エージェントが動き出したときや終わったときはフックで拾って通知してくれます。

## シェル

### zsh + Starship

シェルは macOS 標準の zsh をそのまま使っています。プロンプトは Starship で、ディレクトリと git の状態だけ出すシンプルな構成です。</br>
`starship.toml` で下記のように簡単に管理できるのが良いです。

```toml title="starship.toml"
format = """\
$directory\
$git_branch\
$git_status\
$fill\
\n$character\
"""

[git_status]
ahead = '⇡${count}'
behind = '⇣${count}'
modified = '!${count}'
```

## IDE

Cursor を入れていますが、差分を見たり検索したりで使い慣れてるだけなので、ほとんど使用してないです。

## AI ツール

### Claude Code

開発や資料作成、タスク管理はほぼ Claude Code 経由です。バージョンは mise で管理しています。</br>
他のAIもたまに使用していますが、Claude Codeに慣れてしまったのと、性能的にも十分なためメインで使用してます。

### Obsidian

今年いちばん効いたのはこれです。AIツールではないんですが、「第二の脳」として Claude Code でノートを作成しています。</br>
日々の記録は Claude Code に書かせています。

- **作業ログの自動化**</br>
Claude Code のセッションの記録から事実だけを抜き出して `claude -p` で要約し、vault にノートとして残しています。「あの作業、なんでこうしたんだっけ」を後から検索できるのがありがたいです。
- **朝と夜のコマンド**</br>
`/morning` でカレンダーとタスクをその日のデイリーノートに流し込み、`/evening` で GitHub と Claude Code の動きをまとめます。
- **タスク管理は GitHub Projects に一本化**</br>
vault にはタスク台帳を作らず、`/task` で issue を立てて Project に載せています。
- **AI が要らない処理は launchd で毎朝回す**</br>
索引の作り直しや vault の点検みたいな決まった処理は、AI を挟まずに cron 的に回しています。
- **その他**</br>
SlackでのやりとりやGoogle Driveにある議事録などからも情報を取得し、整理するようにしています。これらの情報からタスクやメモの作成もできるようにしてます。

ルールは vault 直下の `CLAUDE.md` にまとめています。「外部のデータは vault に写さない（リンクと要約だけ置く）」「frontmatter が無いノートは作らない」みたいなものです。Claude Code がこれを読んで、ルールどおりにノートを書いてくれます。

## ランタイム / パッケージ管理

- **Homebrew**</br>
GUI アプリと、mise で入れないコマンドラインツール。
- **mise**</br>
言語ランタイムと CLI ツール全般。去年 asdf から乗り換えました。

## Git / GitHub まわり

- **gh CLI**</br>
PR や issue の操作、GitHub Projects へのタスク登録に使っています。
- **lazygit**</br>
`lg` のエイリアスで起動。差分を見ながらステージしたいときに便利です。
- **Renovate**</br>
このサイトでは Dependabot をやめて Renovate にしました。patch / minor は CI が通れば Renovate が勝手にマージしてくれて、major だけ自分で見ています。

## その他

### 開発系

- **OrbStack**</br>
Docker Desktop の代わり。速い。
- **aws-cli**</br>
AIに使わせてよくデバッグさせてます。

### 開発系以外

- **Remotion**</br>
プロトタイプを実装した際に、動画を撮るケースがあるため、サクッとAIで作らせるときは Remotionを使用しています。
- **Raycast**</br>
ランチャー / ウィンドウサイズ変更。
- **Hammerspoon**</br>
Chrome の垂直タブ（サイドバー）の開閉を `ctrl+A` に割り当てています。Chrome を使っているときだけ有効にしているので、ほかのアプリでは `ctrl+A` が普通に効きます。
- **Karabiner-Elements**</br>
USキーをしているため、左右の ⌘ を単体で押したら英数 / かなを切り替えれるようにする。
- **Clipy**</br>
クリップボード履歴。
- **MeetingBar**</br>
カレンダーにある次の日までの予定をメニューバーに出してます。
- **Google 日本語入力**</br>
Macの変換が無理すぎてこれ使ってる。

## 去年からの変化

| Before | After | 理由 |
| --- | --- | --- |
| WezTerm + tmux |  Orca | エージェントのセッションを管理しやすくしたかった |
| Dependabot | Renovate | 自動マージの条件（CI が全部通ったら）を細かく決めたかった |
| メモはその場限り | Obsidian + Claude Code | 作業ログや判断の経緯を、後から検索できる形で残したかった |


## おわりに

振り返ると、ターミナルはエージェントの置き場所になって、メモはエージェントに書いてもらうものになりました。</br>
今年は新しいツールが出まくってたので、手当たり次第に試してこの環境に落ち着いたって感じです。
なるべくシンプルに保っていきたいです。
